7.Bitwise Operator
0 is false and 1 is true
5 --> 0101
3 --> 0011
1 --> 0001

& --> Bitsiwe and
print(5 & 3)

| --> Bitwise or
5 --> 0101
3 --> 0011
7 --> 0111
print (5 | 3)

^ -->  Bitwise X0R only one value should be true then the value is 1, if two are true or false then the value is 0
5 --> 0101
3 --> 0011
6 --> 0110
print(5 ^ 3)

>> --> Right shift
5 --> 0101
1 --> 0001
0001
print(5 >> 2)

<< --> Left Shift
5 --> 0101
1 --> 0001
print(5 << 1)
