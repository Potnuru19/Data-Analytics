Dictionary
Dict is a collection of key : value pair
key must be unique and it should be immutable data type
(int,str, tuple)
dict is represented in {}
eg
details = {1: 2,
           'name': 'Samitha',
           (1,2): [1,2]}
print(details)

Accessing
dict can access by calling key, we will get value from thet key
syntax --> dict['key']

get() method is also used to get the value from that key
syntax --> dict.get(key)
eg
data_ = {'name':'samitha',
         'balance':7000,
         'Adr':1234567897654,
         'PANC':'GQPK8461K',
         2:[3,4]}
print(data_['Adr'])
print(data_.get(2))

update()
Method is used to update a key, incase the key is not present inside the dict then it add  that key:value
syntax --> dict.update({key:value})

There is another way to update a key
syntax --> dict[key] = value
eg
data_ = {'name':'samitha',
         'balance':7000,
         'Adr':1234567897654,
         'PANC':'GQPK8461K',
         2:[3,4]
         }
print(data_)
data_['AC'] = 12345676548

data_.update({'age': 23})
data_.update({'ATMPIN': 7899})
print(data_)

values()
Values() method is used to get all the value from the dict
syntax --> dict.values()
eg
data_ = {'name':'samitha',
         'balance':7000,
         'Adr':1234567897654,
         'PANC':'GQPK8461K',
         }
print(data_.values())

keys()
keys() method is used to get all the key from the dict
syntax --> dict.keys()
eg
data_ = {'name':'samitha',
         'balance':7000,
         'Adr':1234567897654,
         'PANC':'GQPK8461K',
         }
print(data_.keys())

items()
The method will get the key:value separated from the dict
syntax --> dict.items()
eg
data_ = {'name':'samitha',
         'balance':7000,
         'Adr':1234567897654,
         'PANC':'GQPK8461K',
         }
print(data_.items())

clear()
clear() method is used to del all data from dict
syntax --> dict.clear()
eg
data_ = {'name':'samitha',
         'balance':7000,
         'Adr':1234567897654,
         'PANC':'GQPK8461K',
         }
print(data_)
data_.clear()
print(data_)

del()
eg
data_ = {'name':'samitha',
         'balance':7000,
         'Adr':1234567897654,
         'PANC':'GQPK8461K',
         }
print(data_)

del data_['Adr']
print(data_)
data_.clear()
print(data_)

Statements
1. if statement
if condition become true, the it will execute inside block of code
incase it becomes False, then it will never enter inside block
eg
age = 20
if age>=18:
    print('Eligible to vote')
print(age)

eg
a = 90
b = 78
if a>b:
    print(a)

2. if else
else for if statement is a fall-back statement, incase if condition is false then else block will execute
eg
age = 15
if age>=18:
    print(f'your {age} Eligible to vote')
else:
    print(f'your {age} you have to wait {18-age}')

a = 90
b = 780
if a>b:
    print(a)
else:
    print(a)
